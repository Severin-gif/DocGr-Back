# Резюме проекта и общий чат

Композер отправляет `task=chat`. Модель предлагает до трёх следующих действий. Выбранный чип отправляет отдельную задачу, сервер готовит предложение `needs_user_action`. Применение требует подтверждения пользователя; повтор запроса не дублирует результат.

Фоновый worker проходит извлечённые тексты фрагментами по 10 000 символов и сохраняет заметки с точными цитатами, отпечатком источника и номером фрагмента. Обрабатываются материалы, документы, подготовленные документы и открытые предложения согласования (как предлагаемые изменения). Максимум 5000 источников. Загрузка, OCR, изменения, удаления и согласование инвалидируют резюме. Незавершённые работы продолжаются после перезапуска; неизменённые источники повторно не оплачиваются.

Чат получает только заметки актуальных источников из разрешённого снимка текущего проекта. Память не является доказательством; цитаты проверяются по первичным фрагментам. Бюджет резюме в запросе — 24 000 символов, видимой сводки — 60 000. Пропуски обозначены. Последние четыре обмена диалога передаются полностью, предыдущие сокращённо. По конкретному вопросу дополнительно работает поиск по проекту. Нераспознанные источники не считаются проверенными.

`DOCGRID_AI_MONTHLY_HOURS` — бюджет времени обращений к модели на владельца по всем проектам за календарный месяц UTC; по умолчанию 1 час. Это не время юриста и не токены провайдера. Учёт общий для чата, фонового резюме и проверки PR. Дневной лимит запросов сохраняется. Перед вызовом атомарно резервируется 90 секунд, после — фактическое время в пределах резерва. При аварийном завершении резерв консервативно остаётся списанным; расчёт идемпотентен. Остатка меньше 90 секунд недостаточно для нового вызова.

При исчерпании времени, отключённом ИИ, сбое модели или неполном OCR отображается красное «Проверка не пройдена» вне композера. Загрузка и ручное согласование остаются доступны. Старая сводка помечается как устаревшая. Успешная обработка не подтверждает законность юридических выводов.

Порядок развёртывания: AI Orchestra с `/internal/docgrid/context` → DocGr-Back с миграцией `20260929180000_project_context` → frontend. Ключи и маршрутизация прежние. `DOCGRID_CONTEXT_ENABLED=false` отключает worker; настройка LLM проекта соблюдается. Одна фоновая обработка одновременно во всех репликах, цикл 5 секунд, повтор ошибки через 5 минут.

Проверки выполняются на синтетических данных и локальном ответе провайдера. Работа реальной модели и деплой Timeweb требуют отдельной проверки.
